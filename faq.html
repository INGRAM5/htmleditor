О программе
Краткое описание
HTML Editor — это мобильный векторный редактор для создания простых графических композиций прямо на телефоне. Программа позволяет рисовать фигуры, редактировать их форму, настраивать цвета и экспортировать результат в HTML или PNG.
💡 Совет: Нажмите на любой раздел ниже, чтобы раскрыть подробное описание его функций.
Верхний остров
Основные инструменты
Верхняя панель содержит основные инструменты управления холстом. Расположена вверху экрана и всегда доступна.
Фон холста
Открывает меню выбора цвета фона. Доступные варианты:
  • Прозрачный — фон без цвета (по умолчанию)
  • Белый — чистый белый фон
  • Тёмно-серый — приглушённый тёмный
  • Чёрный — полностью чёрный
  • Свой цвет — открывает полный колорпикер для выбора любого оттенка
Сетка и привязка
Включает/выключает сетку на холсте. Когда сетка активна, все фигуры и точки автоматически привязываются к её узлам — это помогает создавать ровные композиции. При активации иконка становится белой.
Экспорт
Открывает панель экспорта с двумя форматами:
  • HTML код — генерирует адаптивный HTML-файл с SVG-графикой. Фигуры автоматически масштабируются под экран устройства без обрезки краёв. Доступны кнопки: Копировать, Предпросмотр, Скачать.
  • PNG изображение — сохраняет текущий вид холста как растровое изображение. Файл автоматически открывается и скачивается.
Слои
Открывает панель слоёв, где отображаются все объекты на холсте. Здесь можно:
  • Выделять объекты галочками (несколько галочек = группировка)
  • Менять порядок слоёв (поднять/опустить)
  • Переименовывать объекты
  • Управлять видимостью (👁) и блокировкой (🔒)
Группировка: Отметьте галочками несколько объектов — они будут двигаться вместе как единое целое.

Нижний остров
Добавление фигур и история
Нижняя панель содержит кнопку добавления новых объектов и кнопки отмены/повтора действий.
Отменить (Undo)
Возвращает на один шаг назад. Отменяет последнее действие (добавление, перемещение, изменение цвета и т.д.). Также работает сочетание клавиш Ctrl+Z.
Добавить объект (+)
Открывает меню выбора типа фигуры. Доступные варианты:
Произвольная фигура
Создаёт фигуру в режиме редактирования точек. Изначально — только контур (без заливки).
  • Перетаскивайте точки — меняйте форму
  • Двойной клик по точке — удалить точку (минимум 3)
  • Клик по грани — добавить новую точку
После создания формы можно добавить заливку через кнопку цвета.
Прямоугольник
Создаёт прямоугольник с заливкой. Можно скруглить углы через меню свойств, а также перевести в режим редактирования точек (превратить в полигон).
Эллипс
Создаёт эллипс (круг или овал). Масштабируется за угловые точки, вращается за ручку сверху.
Линия
Создаёт линию. Настраивается толщина и скругление концов. Перемещается за конечные точки.
Текст
Создаёт текстовый объект. Двойной тап по тексту открывает окно редактирования. Настраивается размер шрифта.
Повторить (Redo)
Возвращает отменённое действие. Работает только если было выполнено "Отменить". Сочетание клавиш: Ctrl+Y.
Панель кнопок
Инструменты редактирования
Панель кнопок появляется над выделенной фигурой. Содержит инструменты для редактирования выбранного объекта. Автоматически позиционируется так, чтобы не перекрывать фигуру.
Цвет заливки
Открывает меню выбора цвета заливки фигуры.
  • 8 предустановленных цветов
  • Разделитель и блок "Свой цвет" с колорпикером
  • До 3 последних использованных цветов
  • Ползунок прозрачности (0-100%)

Контур и толщина
Открывает меню настройки контура фигуры.
  • Выбор цвета контура (белый, чёрный, фиолетовый, свой)
  • Ползунок толщины (0-24 px)
  • История последних цветов
Свойства (Перо)
Открывает меню дополнительных свойств фигуры. Содержимое зависит от типа:
  • Прямоугольник/Фигура: режим редактирования точек (полигон), скругление углов
  • Текст: размер шрифта
Режим полигона: кнопка "Режим редактирования активен" — нажмите чтобы выйти из режима и сохранить форму.
Пипетка
Инструмент выбора цвета с холста. После нажатия курсор превращается в прицел — нажмите на любой пиксель холста, чтобы скопировать его цвет в заливку выбранной фигуры.
Дублировать
Создаёт копию выбранного объекта (или группы объектов). Копия появляется со смещением +20px по X и Y. Если объекты были сгруппированы — копия создаётся без группы.
Удалить
Удаляет выбранный объект (или группу). Также работает клавиша Delete или Backspace. Заблокированные объекты удалить нельзя.
Управление
Жесты и горячие клавиши
Основные способы взаимодействия с программой.
👆 Выделение фигуры
Тапните по фигуре на холсте — она выделится, появится панель кнопок и рамка с точками изменения размера.
✋ Перемещение
Зажмите выделенную фигуру и тяните. Если фигура в группе — двигаются все объекты группы. Пустое место на холсте — панорамирование (перемещение вида).
🔄 Масштабирование
Тяните за угловые точки рамки (белые квадраты). Для текста — меняется размер шрифта пропорционально.
🔃 Вращение
Тяните за круглую ручку сверху от фигуры. При включённой сетке — поворот с шагом 5°.
🤏 Зум двумя пальцами
Разведите или сведите два пальца на холсте для масштабирования вида. Работает как pinch-to-zoom.
✏️ Редактирование текста
Двойной тап по текстовому объекту открывает окно ввода нового текста.
⌨️ Горячие клавиши
  • Ctrl+Z — отменить действие
  • Ctrl+Y — повторить действие
  • Delete / Backspace — удалить выделенный объект
💡 Перетаскивание меню: Любое всплывающее меню можно временно отодвинуть — просто потяните за его область. При следующем движении фигуры меню вернётся к автоматическому позиционированию.
